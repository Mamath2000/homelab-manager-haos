# Homelab Manager Agent (dev)

Version de **développement** : mêmes réglages et même fonctionnement que l'application [homelab_agent](https://github.com/Mamath2000/homelab-manager-haos/tree/main/homelab_agent),
dont la [documentation](https://github.com/Mamath2000/homelab-manager-haos/blob/main/homelab_agent/DOCS.md) s'applique telle quelle.
Elle suit les releases dev de Homelab Manager, avant leur publication en prod : à n'installer que pour tester.

N'installer qu'une des deux applications (prod ou dev) sur un même Home Assistant.
